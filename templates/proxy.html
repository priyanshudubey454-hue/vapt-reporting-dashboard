This proxy captures request/response metadata from one dedicated Edge profile and stores it in the dashboard history.

  1. Set the authorized scope. Open Assessment details and include the exact lab IP or localhost in scope, plus your permission note. Only localhost/private IPv4 hosts listed there are allowed.
  2. Start the proxy. Install mitmproxy from its official Windows installer, then double-click start_proxy.bat. Keep its window open. The proxy listens only on this computer at 127.0.0.1:8899.
  3. Open the isolated browser. Double-click open_lab_browser.bat and enter your authorized lab URL. It launches Edge with a separate profile and routes only that profile through the proxy. The browser's loopback bypass is disabled so localhost lab traffic reaches the proxy; the addon still blocks hosts outside the private scope list.
  4. See requests. Browse the lab in that new Edge window, then return here and open Request history.

Open the lab browser

Start the proxy first. This opens a separate Edge window routed through it. The target must be in your saved authorized scope.

HTTPS note: decrypting HTTPS requires the browser to trust mitmproxy's CA. This launcher isolates proxy settings, but Edge's certificate trust is not isolated to that profile. This starter workflow is for HTTP lab targets; do not install the CA in Windows' trust store or click through certificate warnings. The CA key is kept in an ignored local project folder.

What gets recorded

Method, host, URL, response status, header names/values (sensitive values redacted), transfer sizes, and passive review observations. Request and response bodies are not saved.

What this version does not do

It does not pause/edit/replay requests, crawl pages, send exploit payloads, or test public websites. Out-of-scope hosts are blocked. A passive “Review” observation must be verified before you add it as a vulnerability.

Official setup references: Windows installation · Certificate setup

Use only with written authorization and a dedicated lab browser profile.
